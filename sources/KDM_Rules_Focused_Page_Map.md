# KDM Rules-Focused PDF Page Map

This map connects the page number in `KDM_Rulebook_1.5_Rules_Focused.pdf` to the original scan and to the printed rulebook page shown in the footer.

## Numbering notes

- Revised PDF page 1 is the preserved table of contents from original PDF page 2.
- Original PDF page 3 is the separate unnumbered Strain System sheet.
- Original PDF page 5 visibly carries printed page 2.
- From original PDF page 7 onward, printed page = original PDF page - 4. This was visually checked at original PDF pages 7, 26, 28, 171, and 239.
- The printed page column records the number visible in the source, not the new sequential page number in the revised PDF.
